# 设计与架构 · 0.2

Luma TV 以 tvOS 的空间比例、简洁布局及焦点反馈为参考，使用自有背景和本机真实应用资源。首页不显示大标题、虚构推荐、观看进度或不可用按钮。

## 首页

首页由固定壁纸和六列应用库组成。默认是用户选择的「深蓝丝绸」，背景素材不随应用切换，焦点移动时有轻微视差。收藏与“全部应用”收起时停在画面底部，保留圆角磨砂玻璃底板；向下呼出网格时两排同步升到顶部，玻璃底板淡出，收起时同步回到底部并恢复。两排共用一个展开380ms、收起320ms的FastOutSlowIn缓动进度，图块布局尺寸和间距不变，中途反向从当前位置收回。展开后下面的应用在固定视口内滚动，壁纸只增加轻微压暗。第一排直接启动应用，向上保持当前焦点，不再进入背景上的隐形焦点区域。上半部以“日期在上、时间在下”的时钟形成视觉重心，读取设备本地时间，不接收焦点；展开网格时提前淡出，收起时恢复。没有可见的横卡或大标题。

托盘显示前五个收藏与“全部应用”。没有收藏时使用前五个电视应用，正式入口先于开发变体。更多收藏和其余电视应用去重后出现在网格中，再提供设置与管理入口。应用数量取决于真实安装情况。

以 960×540dp 逻辑窗口为基准：

| 元素 | 规格 |
|---|---|
| 横向安全区 | 默认48dp，可选56/64dp |
| 固定壁纸 | 深蓝丝绸使用sigma48px高斯模糊，关闭模糊时恢复清晰版。焦点列驱动±8dp水平视差（1000ms），展开时竖向移至-6dp（800ms），画面从1.045倍推近到1.08倍；不切换背景素材。展开仍增加10%深色罩层 |
| 时间日期 | 水平居中，顶部在窗口高度22%处；日期在上、时间在下，两者间距2dp。24小时制96sp细体、等宽数字，`#F6FAFC`纯色加下偏移8dp、模糊30的深蓝投影——阴影必须与纯色配合，用渐变brush绘制文字会让阴影一并染色成大光晕。日期16sp、字距2.2sp：中文日期用主文字70%不透明，中间分隔点用34%，星期用强调色中黑，形成轻量的三段层次。按分钟更新，系统时间/时区/日期变化时刷新；展开前45.5%进度内淡出，轻微上移与缩小，在网格进入该区域前移除，反向收起时恢复 |
| 第一排 | 收起时按窗口高度减图块高度再减24dp定位，贴近底边保留24dp安全留白；展开y52dp，位置由统一进度插值。整排取安全区内可用宽度的85%并居中，五比三图块与下方网格共用六列宽度和23dp列距，默认安全区下约103×62dp；应用不足五个时仍从第一列对齐 |
| 首排底板 | 收起时保留圆角23dp磨砂玻璃，四周外扩12dp，18dp阴影；160×90壁纸缩略图按静止位置取切片后拉伸，以48%不透明度绘制，叠加13%浅深蓝材质和5.5%→1.5%高光，0.75dp渐变边缘高光。随统一展开进度淡出，展开完成后不绘制；不参与焦点或改变图块布局 |
| 图块内容 | 应用自己的宽幅横幅满铺（Crop）——这是 tvOS 图块的本体；没有横幅的电视应用才退回图标：不透明图标满铺，透明标记占高度62%（方形）/56%（宽幅）居中，底色取图标饱和度加权主色并限亮（覆盖率高时上限0.24，否则0.19），无色或过亮时退回深色 `#171C24`；只有图标在绘制后裁掉透明边，横幅保留自己的留白 |
| 应用网格 | 六列五比三图块、圆角18dp，列距23dp、行距22dp；展开后下方网格首行约y136dp，按实际窗口与安全边距从第一排高度推导，和第一排共用22dp行距 |
| 名称 | 只显示焦点项：网格13sp，首排15sp中黑。首排名称固定在同一位置（托盘左侧、图块上方36dp，20dp高），宽度不随名称长短抖动；按光标而非已落地焦点渲染，连续快速移动时也不会闪断。首排名称切换按方向滑动：旧名称90ms内淡出，同时在140ms内朝上一项方向滑出；新名称延迟100ms后，160ms淡入并从新方向滑入26dp，两段几乎不重叠，避免两串文字同时可读。下方网格名称在图块下方淡入；使用真实名称和Beta/Debug等变体后缀 |
| 焦点反馈 | 首页图标放大1.06（减少动态效果时1.012）、上移3dp，16dp阴影；其他页面保留1.075、4dp及20dp阴影，静止无阴影 |
| 焦点范围 | 只在可见的应用和操作入口之间移动，背景不接收焦点；旧`@hero:`书签恢复到同一应用的可见图块 |
| 布局过渡 | 首排位置、网格位置/透明度及玻璃退场共用展开380ms、收起320ms的FastOutSlowIn进度，布局尺寸和行距不变。网格图块按行列略微错开，淡入并从96.5%回到100%、上浮12dp，仅改变绘制。减少动态效果关闭视差、推近、分批出现及名称过渡，首排/网格瞬切。保留单个图块的焦点反馈 |
| 网格内容起点 | 运动中网格跟随首排，首个图块始终位于第一排底部加22dp，网格同步淡入/淡出。完全收起后视口停在窗口底边外32dp并全透明，不露下一行；保持挂载以保留滚动状态及焦点交接。视口含16dp顶部留白，供焦点放大与抬升使用 |

主文字 `#F5F7F8`、次文字 `#D1DDE1`、强调色 `#D8E9ED`，面板底色 `#354A58`。设置标题32sp、正文18sp、值16sp。减少动态效果独立控制缩放、抬升和过渡。

收起时只有首排带磨砂玻璃底板；展开后首排与网格的图标直接浮在背景上，靠单项缩放、阴影和压暗表达层级。不使用卡片描边或内嵌标题条。tv-material 默认的 focus 光晕与描边由 `quietBorder()`/`quietGlow()` 关闭，避免出现非设计的细亮环。

网格及分批出现图层使用`CompositingStrategy.ModulateAlpha`完成淡入，让焦点放大、抬升和阴影可以超出单元格原始尺寸。默认Auto在透明度小于1时创建按单元格尺寸裁切的离屏层，会在展开中间帧截断圆角和阴影；参见[Compose绘制与合成说明](https://developer.android.com/develop/ui/compose/graphics/draw/modifiers)。应用图块自身的圆角裁切保留。

## 背景与资源

默认背景是深蓝丝绸：海军蓝褶皱、银蓝边缘光和安静的下半场，给彩色应用图块和玻璃托盘留出层次。用户选择方向后，使用内置图像生成工具从批准的示意图生成无界面源稿，实际1672×941。来源及完整提示词见[素材说明](../design/assets/ambient-source-v4.md)。`design/export-background.cjs` 将源图按16:9裁切导出1920×1080 JPEG；模糊版先复制外扩144px、执行sigma48px高斯模糊后裁回原尺寸，避免黑边并形成明显柔焦光带。工具需要Sharp，仅用于设计导出，不是Android运行依赖；v3暖琥珀源稿留作历史素材。

Android在IO线程解码并缓存默认图片，不逐帧执行全屏模糊。其他内置背景和导入图片使用三次滑动盒式滤波近似高斯，宽度上限1280，API26+可用。首页背景罩层为其他页面强度的22%，下方另加渐进深蓝罩层：40%高度前透明、68%高度40%、底部88%，将主要光区留在上半部；展开网格额外增加10%深色压暗。壁纸始终可见，只有缓存图层参与位移和缩放，不再叠加应用横幅或逐帧执行高斯模糊。首排磨砂底板取壁纸在收起位置的缩略图切片，仅在素材或几何改变时生成，不在动画每帧重新取样。这是近似磨砂，不使用Apple私有材质或实时backdrop blur。

`backgroundBlur` 默认true，旧配置缺省也为true，与 `reducedMotion` 独立持久化，不按设备内存自动关闭。用户关闭后使用清晰背景及更浅的渐变罩层。旧 `dusk` 键映射当前默认背景，收藏、排序、隐藏及其他背景选择保留。

应用横幅由PackageManager读取，优先TV banner，后台绘制至最多800×450；缺失时使用真实图标，再退回应用首字。缓存上限12MiB，最多两个并行读取任务。图片低分辨率问题不会由放大解决。应用不内置已安装应用的图标包。

## 遥控器与状态恢复

方向键按卡片行列与实际空间位置移动。焦点缩放只改变绘制，不改变布局尺寸。首次进入默认聚焦托盘第一个应用；恢复时优先使用保存的稳定组件ID，应用卸载后回退到相邻位置。

逻辑目标与实际焦点分开维护，连续输入不必等待动画。`DeferredConfirmation` 在延迟焦点请求期间把完整确认按下/抬起交给最新目标，避免打开旧卡片；离开页面前立即取消旧请求。设置右侧内容尚未挂载时，后续上下/确认事件按顺序交给挂载后的内容，不由旧分类消费。

返回键依次处理排序取消、弹窗关闭、设置内容回分类、返回来源页及网格收起。排序、隐藏与恢复均有方向/确认/返回路径，长按只是快捷方式。页面及外部应用返回时恢复原焦点、展开状态和滚动位置，启动应用前先持久化。

## 职责

| 文件 | 职责 |
|---|---|
| `MainActivity` | 窗口、前台恢复、包变化通知 |
| `LauncherModel` | 异步加载、配置更新、启动前位置保存 |
| `AppRepository` | 发现启动入口、读取资源、显式Intent启动 |
| `ConfigStore` | DataStore本机原子持久化 |
| `LumaApp` | 路由、管理弹窗及排序状态 |
| `HomePage` | 固定壁纸取色的dock、时间日期区退场、焦点名称、网格、空间导航与焦点恢复 |
| `HomeClock` | 设备本地时间与中文日期显示、分钟及系统时间变化更新，不接收焦点 |
| `Theme` / `BackgroundImages` | 统一卡片、按钮及背景处理 |
| `SettingsPage` | 外观、应用管理、默认桌面与关于 |

优先发现电视入口，再按包去重获取普通启动入口。仅显示当前用户下启用、可导出的应用，排除自身。无启动入口的包不显示，普通应用进入兼容分组。应用回到前台重新查询，安装/更新/卸载通知使资源缓存失效。

收藏排序与全部应用排序独立；隐藏不销毁收藏。卸载后保留稳定组件偏好，同组件重装可恢复。组件名变更暂视为新入口，不自动按包迁移。只读取当前用户，不跨用户或读取其他应用私有数据。

本地图片通过系统文件选择器导入，在后台缩采样并保存至应用私有目录，不申请存储权限。应用不声明网络权限，不添加账号、广告、遥测或常驻服务。

## Launcher

普通入口与默认关闭的HOME alias分离。用户主动设置时启用alias，API29+检查ROLE_HOME，否则尝试HOME_SETTINGS。系统返回后分别检查角色和实际Home解析；OEM可能固定Home，状态提示不能替代按键实测。

原桌面始终保留。测试前记录原组件及恢复方式，不禁用原桌面、不使用无障碍抢Home。已知测试模拟器可授予角色，但优先级更高的原桌面仍处理Home，详见[验证记录](validation.md)。

## 后续边界

不预先加入内容聚合、账号、观看记录、云服务或后台常驻服务。继续观看和内容直达必须依赖公开数据、接入方主动提供的数据或合法深链，不能假定可读取其他应用内部观看记录。
